项目背景

为配合公司旗下艺人进军欧美市场的新 MV 宣发，主导设计名为《If... Arrives》的系列 YouTube，Pinterest 贴片广告。针对欧美受众对传统“高饱和、重包装”偶像视觉的审美疲劳，确立了以“电影叙事（Cinematic Narrative）”和“末日反差美学”为核心的视觉重构策略，旨在突破贴片广告“5秒跳过”的注意力瓶颈。

核心贡献与技术实施
✦ 跨文化美学降维定位：

摒弃常规偶像广告的糖水色调，精准切中欧美年轻圈层推崇的“A24 独立电影质感”与“废土/末日（Apocalyptic）美学”。通过引入 35mm 胶片颗粒与极端的冷暖光影对撞，为 Idol 打造极具国际化与先锋感的高奢视觉人设。

✦ “黄金5秒”注意力工程与 Sora 调度：

针对贴片广告的转化漏斗，利用 Sora 实现了极高难度的动态张力控制。0-2秒以“电视雪花+末日警报”的剧烈手持镜头制造全局恐慌（视觉 Hook），紧接着在第2-4秒以极致平稳的慢镜头切入海滩与冰块气泡微距特写（Macro Shot）。通过动静结合与极端的感官反差，强制锁定用户注意力。

✦ AIGC 工业化管线与物理真实感：

深度调优 Sora 提示词模型，攻克复杂物理交互难题。完美呈现了“防晒喷雾在阳光下形成的虹光物理反馈”与“陨石坠落的高光反射”，确保最终成片达到好莱坞级别的商业交付标准。

业务数据与 A/B 测试价值

通过 AIGC 管线，团队得以用极低成本进行高规格视觉的 A/B 测试。其中 Case B (Meteorites 末日反差主题) 表现出惊人的数据爆发力，成功建立了一套适用于海外高要求市场的 AIGC 投流视觉范式。

技术实施与工作流
✦ 数据精筛与标签工程 (Dataset & Tagging)：

基于多光影、多视角特征搜集高质量切片构建训练集。使用 WD14 Tagger 进行底层特征提取，随后在 DTE (Dataset Tag Editor) / BDTM 中进行深度的**人工清洗与干预**。将核心概念有效分离（Concept Decoupling），确保特征与触发词绑定，而非被公共特征污染。

✦ 模型训练与监控调参 (Kohya & Tensorboard)：

依托 Kohya_ss 本地或云端环境，结合素材特征规模精准设定 Network Rank (Dim)、Alpha 及 Learning Rate。在预训练过程中，全程接入 Tensorboard 实时监控 Loss 曲线走向，及时定位拐点，输出并比对多组 Epoch 权重，保障最佳泛化性。

AIGC 炼丹避坑：警惕“标签污染”与“过拟合”

过去纯靠“堆积海量网图、无脑自动打标”的旧思路已无法适应工业级交付。最易导致 LORA 彻底报废的坑在于标签污染（Tag Contamination）——若不以人工干预清洗掉特征标签，AI 会把角色专有特质当成公共属性，导致死活唤不出指定效果。此外，通过 Tensorboard 规避过拟合（俗称“烤焦”）更是重中之重，盲目追求极低的 Loss 只会让模型丧失在新底模下的泛化能力。

“不被 AI 的随机性盲盒绑架，依靠系统性的审美沉淀进行精准干预。” 游戏&游戏设计实战所沉淀的系统性审美，与对透视、光影解剖的深刻理解，是我如今驾驭 AIGC 视觉管线的坚实基石。这使我能在面对 AI 泛滥的“同质化”与“塑料感”时，依靠精准的人工美学干预（Human-in-the-loop），将画面重新锚定至顶级商业交付标准。以下是我早年积累的部分传统美术实战案例。

09

欧美卡通风格游戏《才不是童话》日韩台上线

The dark fairy tale-style mobile game "It's Not a Fairy Tale"

Dark Fairy Tale / Mobile Game / Scene Design

* 图片为无 UI 和角色状态下战斗场景，右图为游戏网络截图

项目说明

《才不是童话》是一款主打“暗黑童话”风格的策略放置类卡牌 RPG 手游。作为核心场景原画师，我深度参与了游戏世界观的视觉构建，主要负责核心关卡地图与无缝大地图的绘制。在设计中，通过对冷暖色调的精准把控与碎片化叙事元素的植入，成功确立了游戏诡谲而不失精致的独特美术调性，助力产品在日韩台等海外市场取得优异的商业表现。

10

女性向恋爱&换装游戏《依依恋物语》与《七日恋人》

Otome Romance & Dress-up Games

Otome Game / Romantic Fantasy / 2D Illustration
美学沉淀

作为早期的核心二次元项目经历，深度参与了女性向换装与恋爱养成游戏的美术研发。该图展现了经典的奇幻浪漫氛围与精致的二次元细节构图。

经验转化

在该类项目中，重点打磨了对女性向游戏色彩心理学（如梦幻、唯美、轻表现）的敏锐度，以及高精度 2D 插画的构图张力。这为后期使用 AIGC 驾驭精细唯美画风打下了坚实的手绘基础。

11

日本动画《物语系列——化物语，伪物语》

Japanese Anime Series "Bakemonogatari & Nisemonogatari"

Japanese Anime / Background Art / 2D Layout
项目说明

参与日本经典动画《物语系列——化物语、伪物语》制作，核心负责场景原画设计相关工作，严格遵循导演分镜脚本及创作意图，精准把控动画场景的风格调性、空间布局与细节呈现，确保场景与角色动作、剧情氛围高度契合。
工作过程中，深入研读分镜脚本，拆解导演对场景的光影、色调、透视及氛围要求，绘制符合动画整体暗黑奇幻风格的场景原画，涵盖日常场景、奇幻场景等多种类型，配合团队完成原画审核、修改迭代，保障场景原画按时交付，助力动画画面的流畅呈现与风格统一。

同时，同步参与公司Q版手办建模项目，结合动画角色的核心特征，协助完成Q版角色的建模设计、细节优化工作，兼顾手办的可爱调性与角色辨识度，配合建模团队完成模型调整、适配等相关事宜，确保手办建模符合项目要求，助力项目顺利推进。
